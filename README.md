# Jung

This repository has two top-level directories:

- frontend/: the Next.js and TypeScript website. See its [README](frontend/README.md) for setup and development commands.
- backend/: the Django foundation for jung-api. See its [README](backend/README.md) for setup, checks, and the operational health endpoint.

To run the website, change into frontend/ and follow its README. To run the API, change into backend/ and follow its README. Each application keeps its own local dependencies and environment file.

When you are ready to create a local Git repository, run git init from this root so that frontend and backend share one history. No remote is configured.
