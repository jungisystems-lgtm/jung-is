# Documentation instructions

This directory explains how Jung is engineered. Read the repository and frontend AGENTS.md files before editing it.

- Write all Markdown in English.
- Keep the Engineering Constitution focused on durable principles. Do not silently weaken or contradict agreed principles.
- Keep architecture.md aligned with the implementation. Describe current boundaries and identify open decisions rather than presenting plans as completed features.
- Record consequential implementation choices in adr/. Explain why a choice was made and what it costs.
- Update the relevant document when code changes make it inaccurate. Avoid duplicating the same rule across multiple documents.
- Major architecture, public contract, tenant isolation, and database decisions require human review under the Constitution.

## Change log

After changing any project-owned file in this directory, append one entry per changed file to the repository-root agent-log.md before finishing the task. Follow the format, exclusions, and append-only rule in the root AGENTS.md.
