# Public asset instructions

This directory contains static files served directly by the frontend.

- Add assets only when a real page or feature uses them. Keep names clear and reusable.
- Do not place secrets, private customer data, or environment configuration here; public files can be fetched by anyone.
- Optimize large assets and use appropriate formats. Provide accessible text where the asset is rendered in a component.
- Keep branding-specific assets separate from shared component behavior. Do not add customer-specific copies without a demonstrated product need.

## Change log

After changing any project-owned file in this directory, append one entry per changed file to the repository-root agent-log.md before finishing the task. Follow the format, exclusions, and append-only rule in the root AGENTS.md.
