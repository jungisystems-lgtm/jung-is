# Component instructions

This directory owns reusable presentation components.

- Keep components focused, accessible, and responsive. Use clear props for legitimate variation.
- Do not fetch from jung-api or own lead, booking, messaging, or tenant rules here. Page or feature code supplies data.
- Keep site-specific copy and branding in ../config when practical.
- Reuse demonstrated patterns. Avoid generic component frameworks or customer-specific branches before they are justified by actual use.
- Add interaction tests when behavior matters; avoid tests that only repeat rendered markup.

## Change log

After changing any project-owned file in this directory, append one entry per changed file to the repository-root agent-log.md before finishing the task. Follow the format, exclusions, and append-only rule in the root AGENTS.md.
